
# Summary（量化方向准备要点）

1. **quant方向极卷**，需要很高的执行力，很早的规划和很强的technical skills，基本画像为top院校的毕业生，国际奥赛奖牌得主，coding skills和talents非常强的人。（无括号，直接作为背景）

2. **打破信息差靠的是实习+竞赛**  
   （如：**IMC Prosperity**（顶级模拟做市竞赛）、**Optiver 交易竞赛**、**WorldQuant IQC**（全球最大规模alpha挖掘）、**Bloomberg Global Trading Challenge**、**G-Research 挑战赛**，以及 **ICPC / Putnam / IMO / IOI** 等数学/编程奥赛。竞赛成绩是直接获得面试机会的“快速通道”。）

3. **一等学位足够，控分即可**  
   （但需保持 **65分以上**，确保稳稳拿到 **First Class**。量化公司对成绩有硬性筛选线，一等是最低门槛，不必追求完美，但不可低于二等一。）

4. **数学需要学好：微分方程，统计，概率。了解一下量化方向的人究竟在做什么内容，需要用到什么知识，再去学这些知识。可以刷绿皮书**  
   （绿皮书即 **《A Practical Guide to Quantitative Finance Interviews》**，建议反复刷 **2-3 遍**，重点吃透概率、统计、随机过程、微积分和线性代数部分。同时配合 **“刷题+理解金融场景”** 的方式，不要死记硬背。）

5. **高三和大一阶段多去尝试量化方向的各种内容，找到个人兴趣与客观因素重合的地方。**（无括号，建议自行尝试：读《打开量化投资的黑箱》，跑一个简单回测，参加线上模拟交易比赛等。）

6. **实践的项目可以是自己做一个量化模型，自己研究一种模型，自己做机器学习**  
   （例如：用 **Python + Pandas/NumPy** 实现一个 **均值回归或双均线策略**，或者用 **scikit-learn** 构建一个简单的 **因子预测模型**，并在 **聚宽 / 优矿** 等平台上完成回测。项目要 **完整、可复现、有文档**，并上传 GitHub。）

7. **你的专业背景不够垂直，因此你的实践项目要足够垂直。**（无括号，强调项目必须直接体现量化研究/交易能力，而不是泛泛的CS工程。）

8. **很可能需要去读美国的master，本科被录进去概率很小**  
   （尤其是顶级对冲基金的核心量化研究岗。目标硕士项目包括：**CMU MSCF、Baruch MFE、Princeton MFin、Columbia MFE、MIT MFin** 等。这些项目是Citadel、Two Sigma、JS等公司的目标校，且提供暑期实习和全职校招通道。）

## 各方向具体执行

### 1. 数学内容预习（最重要）

**为什么最重要**：牛津工程系的数学难度高，且量化面试的核心就是概率、统计、随机过程。你高三暑假提前学，开学后能更快适应，腾出时间做其他事。

**具体内容**：

| 模块 | 具体内容 | 推荐资源 |
| :--- | :--- | :--- |
| **微积分** | 多元微积分、泰勒展开、微分方程 | MIT 18.01/18.02 OCW |
| **线性代数** | 矩阵运算、特征值、线性空间 | Gilbert Strang 教材 |
| **概率论** | 条件概率、贝叶斯、分布函数 | 《概率论与数理统计》（浙大版） |
| **统计学** | 期望、方差、假设检验、回归 | Khan Academy Statistics |

**目标**：开学前把AP微积分BC的延伸内容（多元、微分方程）过一遍，线性代数系统学一遍，概率论过到中心极限定理。

---

### 2. 量化项目尝试（差异化优势）

**为什么重要**：你的专业是工程而非纯数学/统计，需要用项目证明“我的量化能力不输数学系”。

**推荐项目**（三选一）：

| 项目 | 难度 | 所需时间 | 产出 |
| :--- | :--- | :--- | :--- |
| **A. 双均线策略回测** | 低 | 1-2周 | Python脚本 + 回测曲线图 |
| **B. 因子有效性分析** | 中 | 2-3周 | 分层回测表 + IC分析 |
| **C. 订单簿模拟** | 高 | 3-4周 | 模拟交易引擎 + 文档 |

**工具推荐**：
- 数据获取：`yfinance`（美股）、TuShare/Baostock（A股）
- 回测框架：`backtrader`、`zipline`，或直接用`pandas`手写
- 平台：聚宽、优矿（在线回测，上手快）

**目标**：开学前完成一个项目，代码上传GitHub，写一篇中文README解释策略逻辑和结果。

---

### 3. Spring Week构思（大一黄金窗口）

**什么是Spring Week**：投行/金融公司为大一大二学生开设的1-2周短期实习项目，通常在复活节假期（3-4月）。**这是大一学生进入金融公司最容易的路径**。

**哪些公司开放量化相关Spring Week**：

| 公司 | 项目名称 | 申请时间（预计） | 量化相关度 |
| :--- | :--- | :--- | :--- |
| **Jane Street** | Spring Insight | 大一开学后9-10月 | ⭐⭐⭐⭐⭐ |
| **Optiver** | Future Traders | 11-12月 | ⭐⭐⭐⭐⭐ |
| **Citadel** | Discover Citadel | 9-10月 | ⭐⭐⭐⭐ |
| **Maven Securities** | Spring Week | 10-11月 | ⭐⭐⭐⭐ |
| **IMC Trading** | Spring Week | 10-11月 | ⭐⭐⭐⭐ |

**你现在要做的**：
- 了解Spring Week是什么、申请流程（CV + Online Test + 视频面试）
- 准备一份量化方向的一页CV（突出数学成绩、编程项目、竞赛经历）
- 开学后立刻关注各公司官网的“Early Insight”或“Spring Week”页面
