Container : an isolated environment for development. 
Usually mimics the behavior of linux sys, and can be used as a light VM 
https://github.com/apple/container/blob/main/docs/technical-overview.md

Image : a snapshot of a system in a short time. Debian, red hat, arch etc. can all be stored as an image.

Each container is isolated and is a separate linux system

- In mac, apple container/ DockerDesktop is an instance of using container.
- Create an image/ Pull the image to create a container. Executes the container. These are the normal steps to use a container 
- https://github.com/apple/container/blob/main/docs/tutorials/start-here.md
