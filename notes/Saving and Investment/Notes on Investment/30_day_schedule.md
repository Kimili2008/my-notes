# 30 Day Quant First Schedule

Daily capacity: 12 hours. Use four hours for maths and timed coding, three for finance, four for project work, and one for market notes or applications. Keep one half-day each week for review and recovery.

## Days 1 to 4: Quant test foundation

- [ ] **Day 1**: Run the diagnostic. Create the repository structure. Read OAF Quant and Oxford Quantitative Finance pages. Output: scores, gaps, and a 150-word `Why quant?` draft.
- [ ] **Day 2**: Events, conditional probability, Bayes, independence. Output: 20 solved problems and an error log.
- [ ] **Day 3**: Expectation, variance, covariance, correlation. Output: Python simulations and a one-page formula sheet.
- [ ] **Day 4**: Binomial, Poisson, Normal, CLT, estimation. Output: 20 more problems and a 90-minute mixed mock.

## Days 5 to 14: Momentum research

- [ ] **Day 5**: NumPy/pandas; download and cache one ticker. Output: clean price and return pipeline.
- [ ] **Day 6**: Download the full universe. Output: data dictionary and missing-data report.
- [ ] **Day 7**: Define signal, rebalance calendar, benchmark, and research/OOS split before looking at results.
- [ ] **Day 8**: Implement equal-weight and buy-and-hold benchmarks. Output: benchmark metrics.
- [ ] **Day 9**: Implement 12-1 momentum. Output: first equity curve.
- [ ] **Day 10**: Add inverse-volatility weighting and SPY 200-day regime filter.
- [ ] **Day 11**: Add turnover and 10 bps one-way transaction costs.
- [ ] **Day 12**: Add performance metrics, drawdown, turnover, and regime breakdown.
- [ ] **Day 13**: Run bias checks, parameter sensitivity, and an OOS-only evaluation.
- [ ] **Day 14**: Write the report and 8-slide deck draft. Output: reproducible results folder.

## Days 15 to 19: Derivatives risk lab

- [ ] **Day 15**: Implement Black-Scholes call and put pricing. Test put-call parity.
- [ ] **Day 16**: Implement Delta, Gamma, Vega, Theta. Compare analytical and finite-difference Greeks.
- [ ] **Day 17**: Implement seeded Monte Carlo. Test convergence as path count increases.
- [ ] **Day 18**: Implement daily and weekly discrete delta hedging under GBM.
- [ ] **Day 19**: Add volatility misspecification and jump scenarios. Write the technical note.

## Days 20 to 24: Semiconductor stock pitch

- [ ] **Day 20**: Read AMAT annual report, latest results, investor presentation, and two competitors. Define the question and preliminary view.
- [ ] **Day 21**: Build revenue, margin, capex, and cash-flow history. Output: source-linked model.
- [ ] **Day 22**: Build DCF and multiples valuation. Record assumptions and sensitivity ranges.
- [ ] **Day 23**: Write the differentiated view, catalysts, disconfirming evidence, and risks.
- [ ] **Day 24**: Produce the 2-page memo and 6–8-slide deck; deliver a five-minute spoken pitch.

## Days 25 to 30: Applications and interview

- [ ] **Day 25**: Build the one-page English CV from completed work only.
- [ ] **Day 26**: Complete the OFS technical question set: statements, DCF, EV, WACC, beta, and LBO.
- [ ] **Day 27**: Complete the quant set: probability, estimation, mental maths, and coding under time limits.
- [ ] **Day 28**: Prepare eight STAR stories and answers for Why finance, Why quant, Why OAF, and Why CapitOx.
- [ ] **Day 29**: Run a full 60-minute mock assessment and a five-minute stock pitch. Record both.
- [ ] **Day 30**: Final audit: tests, README, CV, reports, decks, tracker, and next-term plan.

## Daily market journal

Write one entry each day using this format:

```text
Date:
Market event:
Initial interpretation:
What price or data would disprove it:
Relevant asset or sector:
One question to research:
```

## Day 30 acceptance criteria

- The two code projects run from a fresh environment with documented commands.
- The momentum report shows research and OOS periods, transaction costs, benchmarks, and limitations.
- The option lab contains pricing, Greeks, Monte Carlo, hedging, and tests.
- The stock pitch has an explicit view, valuation, catalysts, and disconfirming risks.
- The CV contains no unverifiable claims.
- The mixed mock can be completed in 60 minutes and every error has a written explanation.
