---

## 一、ResNet 之前的大问题：退化问题（Degradation）

### 直觉上你认为：
网络越深 → 表达能力越强 → 效果越好

### 实验发现的事实（VGG 之后）：
- 20 层的网络比 56 层的网络**效果更好**
- 56 层的训练误差比 20 层还高

### 这不是过拟合（过拟合是训练好、测试差）：
- 56 层**连训练集上都更差**

### 为什么？
- 梯度消失（梯度反传到前面几乎为 0）
- 更微妙的原因：**恒等映射难以学习**

> 关键洞察：深层网络至少应该能做得和浅层网络一样好（把多的层设成恒等映射就行），但 SGD 优化器**学不会恒等映射**。

---

## 二、核心洞察：改变学习目标

### 传统网络（要学什么）：
```
期望输出 = H(x)
网络直接学 F(x) = H(x)
```

### ResNet 的想法（改变目标）：
让网络去学**残差**：
```
期望输出 H(x) = x + F(x)
网络只学 F(x) = H(x) - x
```

- **x**：输入（来自上一层的恒等映射）
- **F(x)**：网络要学的残差（通常是 2-3 个卷积层）

### 为什么这样更好？
- 如果恒等映射是最优的 → 让网络学 F(x)=0 比学 H(x)=x 容易得多
- 梯度可以**直接走捷径**（跳过卷积层）传到前面

---

## 三、残差块（Residual Block）结构

### 基本残差块（用于 18/34 层 ResNet）：
```
输入 x
    ├─→ [Conv 3×3, BN, ReLU] → [Conv 3×3, BN] → 输出 F(x)
    │                                                    │
    └───────────────── 恒等连接（identity）──────────────→ 相加 → ReLU
```

输出：`y = F(x) + x`

### 瓶颈残差块（用于 50/101/152 层，减少计算量）：
```
输入 x (256 通道)
    ├─→ [1×1 Conv, 64] → [3×3 Conv, 64] → [1×1 Conv, 256] → F(x)
    │                                                              │
    └─────────────────── 恒等连接 ───────────────────────────────→ 相加
```

- 1×1 卷积先降维（256→64），3×3 在小维度上算，再升维（64→256）
- **计算量大幅减少**
（神经网络存储反向转播所需的激活值，这个block使得所需要存储的激活值变少了）
---

## 四、两种残差连接

| 情况 | 做法 |
|------|------|
| 输入输出维度相同 | 直接相加：`y = F(x) + x` |
| 输入输出维度不同（如通道数翻倍时） | 需要对 x 做投影：`y = F(x) + W_s × x`（W_s 是 1×1 卷积） |

**常见模式**：每次池化（尺寸减半）时，通道数翻倍，此时用投影连接。

---

## 五、ResNet 整体结构（以 ResNet-34 为例）

```
输入：224×224×3

Conv1: 7×7, 64核, stride=2 → 112×112×64
MaxPool: 3×3, stride=2 → 56×56×64

Conv2_x: 3 个残差块，64 通道（尺寸不变）
Conv3_x: 4 个残差块，128 通道（第一块下采样，投影连接）
Conv4_x: 6 个残差块，256 通道
Conv5_x: 3 个残差块，512 通道

全局平均池化 → 1000 维全连接
```

### 各型号深度：

| 型号 | 层数 | 说明 |
|------|------|------|
| ResNet-18 | 18 | 基本块 |
| ResNet-34 | 34 | 基本块 |
| ResNet-50 | 50 | 瓶颈块 |
| ResNet-101 | 101 | 瓶颈块 |
| ResNet-152 | 152 | 瓶颈块 |

> 注意：层数统计只算卷积层 + 全连接层，不算 BN、ReLU、池化。

---

## 六、ResNet 与之前网络的对比

| 维度 | VGG | ResNet |
|------|-----|--------|
| 深度 | 16-19 层 | 50-152 层 |
| 核心机制 | 小核堆叠 | 残差连接 + 恒等映射 |
| 梯度传播 | 逐层衰减 | 直通捷径，不衰减 |
| 参数量 | ~138M | ~25M（ResNet-50） |
| 能否继续加深 | 不能（退化） | 能（上千层） |

> ResNet 参数量更少，但更深，效果更好。

---

## 七、为什么残差连接能解决梯度消失？

### 反向传播时的效果：
传统网络：梯度逐层相乘（可能趋近 0）

ResNet：
```
∂Loss/∂x = ∂Loss/∂y × (1 + ∂F/∂x)
```

- 这个 **+1** 是关键
- 即使 `∂F/∂x` 很小，梯度也能通过 `1` 直接传过去
- 前面的层始终能收到梯度

---

## 八、验证你理解了（自测题）

1. **退化问题和梯度消失是一回事吗？**  
   → 不完全是。梯度消失是原因之一，更核心的是优化器难以学习恒等映射。

2. **残差块学的是什么？**  
   → 学的是 H(x) - x，不是 H(x)。

3. **什么情况下需要用投影连接（1×1 卷积）？**  
   → 输入输出维度不同时（通常是通道数变化）。

4. **ResNet 如何做到 1000 层？**  
   → 瓶颈块 + 恒等连接让梯度直通，BN 保证每层数值稳定。

## 九、一个帮你理解的小实验（脑内推演）

假设最优解恰好就是输入 x（即 H(x)=x）：

- 传统网络需要学：`F(x) = x`（很难）
- ResNet 需要学：`F(x) = x - x = 0`（把权重全设成 0 就行）

**这就是 ResNet 的优雅之处。**

# 第一部分：YOLOv1（2016）

**论文**：*You Only Look Once: Unified, Real-Time Object Detection*  
**核心贡献**：首次把检测做成单个回归网络，一步到位。

---

## 1. 网络结构

- **输入**：\(448\times448\times3\)（固定尺寸）
- **Backbone**：受GoogLeNet启发的卷积结构，24个卷积层 + 2个全连接层
- **输出**：\(7\times7\times30\) 的张量

### 输出解释

图像分成 \(S=7\) 的网格，每个网格输出30维：

| 部分 | 维度 | 含义 |
|------|------|------|
| 框1坐标 | 4 | \(x,y,w,h\) |
| 框1置信度 | 1 | \(P(Object)\times IoU\) |
| 框2坐标 | 4 | 同上 |
| 框2置信度 | 1 | 同上 |
| 类别概率 | 20 | 对Pascal VOC的20类 \(P(Class_i\mid Object)\) |

每个网格预测 **B=2个框**，共计 \(7\times7\times2=98\) 个预测框。

> 注意：类别概率是**网格级**的，同一个网格的两个框共享一组类别概率。

---

## 2. 坐标表示（归一化设计）

- \(x, y\)：框中心 **相对于当前网格左上角** 的偏移，范围 \([0,1]\)  
  （例：如果中心在网格正中间，则 \(x=0.5,\ y=0.5\)）
- \(w, h\)：框宽高 **相对于整张图像宽高** 的比例，范围 \([0,1]\)

这样做的好处是**所有坐标值都在0到1之间**，利于回归。

---

## 3. 前向推理与预测解码

网络原始输出是 \(x,y,w,h,confidence,class\_probs\)。

**得到最终检测分数**：
\[
\text{Score}_{ij} = \underbrace{P(Class_i\mid Object)}_{类别概率} \times \underbrace{P(Object)\times IoU}_{置信度}
\]

然后对所有 \(98\) 个框进行 **NMS**（同类去重），输出最终结果。

---

## 4. 损失函数（YOLOv1最需要弄懂的部分）

损失是多项平方和损失的加权组合：

\[
\begin{aligned}
\mathcal{L} = &\lambda_{coord} \sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{obj} \Big[(x_i - \hat{x}_i)^2 + (y_i - \hat{y}_i)^2\Big] \\
+ &\lambda_{coord} \sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{obj} \Big[(\sqrt{w_i} - \sqrt{\hat{w}_i})^2 + (\sqrt{h_i} - \sqrt{\hat{h}_i})^2\Big] \\
+ &\sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{obj} (C_i - \hat{C}_i)^2 \\
+ &\lambda_{noobj} \sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{noobj} (C_i - \hat{C}_i)^2 \\
+ &\sum_{i=0}^{S^2} \mathbb{1}_{i}^{obj} \sum_{c\in classes} (p_i(c) - \hat{p}_i(c))^2
\end{aligned}
\]

### 逐项解释：

| 行 | 含义 | 细节 |
|----|------|------|
| 第1行 | **中心点定位损失** | 仅计算中心点落在当前网格的那个框，\(\mathbb{1}_{ij}^{obj}=1\) 仅对负责物体的框成立 |
| 第2行 | **宽高定位损失** | 对 \(\sqrt{w}, \sqrt{h}\) 回归，**核心动机**：框越小，同样像素偏移对IoU影响越大；开根号让大框和小框的loss贡献更均衡 |
| 第3行 | **有目标时的置信度损失** | 让置信度趋近于预测框与真值框的IoU |
| 第4行 | **无目标时的置信度损失** | 让那些不负责物体的框的置信度趋近于0，权重 \(\lambda_{noobj}=0.5\)，防止背景网格过多把梯度带偏 |
| 第5行 | **分类损失** | 仅在**有物体中心落点的网格**上计算，属于经典平方和损失 |

**权重设定**：\(\lambda_{coord}=5\)（定位权重大），\(\lambda_{noobj}=0.5\)（背景置信度权重小）。

---

## 5. “一个单元负责”在v1里的体现

**规则**：
- 只有**目标中心所在的网格**才对该目标负责
- 该网格有两个预测框，其中与真值框**IoU更高**的那个被指定为“负责框”（正样本）
- 同一个网格的另一框，如果IoU低，也算“无目标”来处理（计算无目标置信度损失）

> ⚠️ 缺点：  
> 1. 每网格至多预测一个物体（中心重合的密集小目标直接漏检）  
> 2. 完全依赖中心点一刀切，正样本数量极少

---

## 6. v1的核心局限

| 问题 | 原因 |
|------|------|
| 小目标检测差 | 只靠粗粒度7×7网格，最后一层特征分辨率低 |
| 密集目标大量漏检 | 每网格最多检测1个物体（2框只取1正样本） |
| 定位不准 | 直接回归坐标，无Anchor先验引导 |
| 泛化弱 | 训练尺寸固定，遇到不同长宽比输入效果骤降 |
| 框的长宽比回归难 | 用平方和损失直接回归 \(w,h\)，没有利用先验 |

# 第二部分：YOLOv2（2017）

**论文**：*YOLO9000: Better, Faster, Stronger*  
**改进策略**：每一项改进都有针对性，积少成多，VOC mAP提升约16个点。

---

## 改进总览

| 改进点 | 效果(mAP增益) | 解决v1的什么问题 |
|--------|---------------|-------------------|
| ①Batch Normalization | +2.4% | 训练收敛慢，需要小心调参 |
| ②高分辨率微调 | +3.5% | 输入突然从分类的224→检测448，不适应 |
| ③引入Anchor | mAP微降，但Recall大幅提升 | 定位不准、每个网格只能预测1个物体 |
| ④维度聚类 | +4.8%（比手动Anchor） | Anchor尺寸纯靠人拍脑袋 |
| ⑤直接位置预测 | +5.0% | Anchor机制下 \(x,y\) 不稳定，前期乱跳 |
| ⑥细粒度特征 | +1.0% | 小目标全靠粗网格不够 |
| ⑦多尺度训练 | +1.4% | 固定448×448分辨率，泛化弱 |
| ⑧Darknet-19 | — | Backbone更轻、更快、更准 |
| ⑨联合训练ImageNet+COCO | — | 可检测9000+类 |

下面逐一展开。

---

## ②高分辨率微调

**做法**：
- 之前分类预训练用的是 \(224\times224\) 的ImageNet
- 先在 \(448\times448\) 的ImageNet上**微调分类10个epoch**
- 再迁移到 \(448\times448\) 的检测任务

**效果**：让网络提前适应高分辨率，检测训练初期不再“懵”，mAP直接+3.5%。

---

## ③引入Anchor（锚框）

v1直接回归 \(x,y,w,h\)，**自由度太大**，定位精度难以提升。

v2的做法：
- 每个网格预设若干个形状固定的Anchor框
- 网络只预测**相对于Anchor的偏移量**
- 把 \(448\times448\) 输入→\(13\times13\) 特征图（移除全连接层，加passthrough）

**效果**：
- Recall从81%暴涨到88%
- mAP略降0.2%，但为后续改进留出巨大空间

---

## ④维度聚类（K-means确定Anchor尺寸）

之前Faster R-CNN的Anchor尺寸**人工指定**。v2发现：自动化选出更适合的尺寸能大幅提升。

**做法**：
- 对训练集中所有真值框的 \((w,h)\) 跑K-means
- 距离度量不用欧氏距离，用IoU距离：
  \[
  d(box, centroid) = 1 - IoU(box, centroid)
  \]
- 聚类得到5个形状（\(k=5\)），分别是适合数据集的典型长宽比/尺寸

**效果**：仅更换聚类Anchor，mAP就 +4.8%。

---

## ⑤直接位置预测（极其关键）

**问题背景**：
Faster R-CNN用Anchor的偏移公式：
\[
x = (t_x \cdot w_a) + x_a, \quad y = (t_y \cdot h_a) + y_a
\]
其中 \(t_x, t_y\) 没有约束，可能导致预测框中心**跑出网格甚至跑到图像外面**，训练前期不稳定。

**YOLOv2的独创做法**：
- 每个网格预测5个参数：\(t_x, t_y, t_w, t_h, t_o\)（后一项为置信度）
- 解码公式：
  \[
  b_x = \sigma(t_x) + c_x
  \]
  \[
  b_y = \sigma(t_y) + c_y
  \]
  \[
  b_w = p_w \cdot e^{t_w}
  \]
  \[
  b_h = p_h \cdot e^{t_h}
  \]

**符号意义**：
- \(c_x, c_y\)：当前网格左上角在图上的坐标（网格索引）
- \(p_w, p_h\)：该Anchor框的宽高（聚类得到）
- \(\sigma(\cdot)\)：sigmoid函数，把 \(t_x, t_y\) 压到 \([0,1]\) 之间

**精髓**：通过sigmoid**强制预测框的中心落在当前网格内部**，既延续了v1“中心点负责”的原则，又解决了Anchor带来的位置不稳定问题。

**效果**：mAP +5.0%，维度聚类+位置预测组合是v2最强单点改进。

---

## ⑥细粒度特征（Passthrough层）

**动机**：13×13的特征图对小目标的表达能力不足。

**做法**：
- 把前一层 \(26\times26\times512\) 的特征图**拆成4份**，重组为 \(13\times13\times2048\)
- 拼接到最后的13×13特征图上

**本质**：类似Residual连接或后来的FPN雏形，让高层特征获得低层纹理细节。

**效果**：小目标mAP +1%。

---

## ⑦多尺度训练

v1输入固定448，泛化差。v2的解决方法：
- 每10个batch随机选一种输入分辨率（320, 352, ..., 608，按32的倍数）
- 网络只在conv+pool上运行（去掉了全连接），尺寸可变
- 测试时可**自由选择速度-精度平衡**：低分辨率快，高分辨率准

---

## ⑧Darknet-19（轻量Backbone）

- 19个卷积层 + 5个最大池化
- 大量使用1×1+3×3卷积减少参数
- 在ImageNet top-5达91.2%，推断仅需55.8亿次运算（远少于VGG等）

---

## ⑨YOLO9000（联合训练）

ImageNet（分类数据）和COCO（检测数据）联合训练：
- 遇到检测数据 → 反向传播全图损失
- 遇到分类数据 → 仅反向传播分类部分
- 用WordTree结构组织类别，实现**超过9000类的检测**

---

# 三、v1 → v2 的核心思想转变

| 维度 | YOLOv1 | YOLOv2 |
|------|--------|--------|
| 输出编码 | 直接回归 \(x,y,w,h\) | 回归相对Anchor的偏移 \(t_x,t_y,t_w,t_h\) |
| 位置约束 | 无 | sigmoid强制中心在网格内 |
| 框宽高 | 任意值 | 以聚类后的先验框 \(p_w,p_h\) 为基准缩放 |
| 特征结构 | 全连接输出固定7×7 | 全卷积，卷积输出13×13 |
| 小目标 | 仅靠粗网格 | 通过passthrough融合细粒度+Anchor提升 |
| 训练尺寸 | 固定448 | 多尺度动态变化 |
| 正样本数 | 每物体1个 | 每物体1个（仍由中心所在网格负责），但每个网格可预测多个Anchor框了 |

---

**一句话总结v1到v2的进化**：  
v1开创了单阶段检测的范式但太糙；v2用Anchor、维度聚类、sigmoid约束位置、多尺度训练和细粒度特征，把单阶段检测推到了“可实用”的水平，同时保留了v1最重要的“中心点负责”核心逻辑。
