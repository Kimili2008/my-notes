
# 魔戒：远征
*5~10 人合作派对游戏*

---

## 一、背景介绍

本作的核心在于魔戒，

魔戒代表着无法抵制的欲望和无穷的力量，不论多么自制，虔诚的生物，在得到魔戒之后都会拼命想将其据为己有。
魔戒最开始是索隆（魔王）制作的戒指，后来遗失了，魔王因此寻找魔戒，想取回自己的力量，重新统治世界。

世界命运已系于至尊魔戒。由于魔戒刀枪不入，只能被火山最深处的烈焰烧毁，一支护戒小队在找到魔戒后，从夏尔（起点城镇）出发，穿越六座城镇，想将魔戒投入末日火山的烈焰。然而索隆（魔王）的间谍已渗入队伍，萨鲁曼（邪恶法师）在暗处施法欺骗，魔王大军从后方步步紧逼。信任稀缺，前路凶险，唯有团结能抵达终点。

---

## 30秒快速上手

1. 主角团拿着魔戒，从6号城镇（夏尔）出发，正方把魔戒送到0号（末日火山）就赢。
2. 每个角色每回合从三件事里选一件：**走1步**（前进/后退）、把戒指**传给同城的人**、或者**抢同城人的戒**（对方理智归零时才能抢成功）
3. 拿着魔戒则每回合**掉1理智**（霍比特人3点，其他人2点）。归零则被魔戒**蛊惑**——原地发呆不能动，直到魔戒离手。
4. 队伍里藏着**2个坏人**（间谍+萨鲁曼），他们互知身份，暗中捣乱。
5. 第3回合起，后方**毒圈**每回合吞一座城（6→5→4…），被吞的人**出局**。
6. 你看不到别人在哪座城镇、魔戒在谁手上——全靠聊天推理，所以你的回合行动有落空的可能。
7. 每个角色都有独特技能，善用才能赢。

注意到，一直让一个人拿着魔戒会让此人被蛊惑，所以好的方式是让魔戒在多人之间合作传递，这也是本作的设计核心理念。

---

## 一、胜利条件

**正方赢**：任意正方玩家带魔戒踏入 **城镇0·末日火山**。

**反方赢**（2人：间谍+萨鲁曼）：
- 毒圈攻占**持戒人目前所在地**（魔戒被魔王夺走）。

## 二、地图一览
地图很简单，直线，按6-5-4-3-2-1-0这样的顺序移动。

|  编号   | 名称   | 规则                                                       |
| :---: | :--- | :------------------------------------------------------- |
| **6** | 夏尔   | 起点。霍比特人开局持戒在此。                                           |
| **5** | 矮人国  | **需≥3人同城**才能向4移动。矮人首次抵达时**激活技能**。                        |
| **4** | 洛汗城堡 | **需≥2人同城**才能向3移动。                                        |
| **3** | 欧尔桑克 | 无门槛。**法师（甘道夫）**抵达→立即变**白袍**（免疫蛊惑/收买），全场最强大角色。            |
| **2** | 风云顶  | 无门槛。**首个通过者**（向1移动时）：公开两反派**两回合前的行动类型**（传递/抢夺/移动），不显示目标。 |
| **1** | 黑门   | 无门槛。**首个通过者**：所有持戒人**理智+1**（不可超过上限）。                     |
| **0** | 末日火山 | 持戒人到达→**正方立即获胜**。                                        |

> **移动失败**：人数不足则原地停留，行动照常消耗。
> **城镇特效**：每座只触发一次。

## 三、每回合做什么

### 第1步：选1项行动（其他人不知道你选了什么）

| 行动 | 效果 |
| :--- | :--- |
| **移动** | 前进/后退1城（受门槛限制，被蛊惑者不能动）。 |
| **传递** | 指定1人，**同城**则魔戒给对方；不同城则失败。 |
| **抢夺** | 指定1人，**同城且对方被蛊惑**则魔戒归你；否则失败。 |

### 第2步：按顺序结算
**法师→战士→精灵→矮人→霍比特人→平民**
> *矮人激活技能后可调换任意两人的结算顺序（每回合一次）。*

### 第3步：回合结束
1. **理智-1**：当前持戒人掉1理智（霍比特人上限3，其他人2）。归零则被**蛊惑**（原地罚站，直到魔戒离手。理智**不恢复**）。
2. **毒圈推进**（第3回合起）：每回合吞最外围一座城（6→5→4→3→2→1→0）。
   - 持戒人在城里 → **反方赢**。
   - 其他人在城里 → **出局**（见下）。
   - 无人在城里：无事发生

## 四、角色技能

| 角色          | 技能                                                                      |
| :---------- | :---------------------------------------------------------------------- |
| **法师（甘道夫）** | 刚开始是灰袍（无技能），到城镇3变**白袍**：理智变为无穷大、免疫收买。                                   |
| **战士**      | 抢夺替换为敲晕：每回合可选**同城1人敲晕**，对方本回合行动作废（如果对方行动结算的比战士早，则不作废）；若对方持戒，可无视理智值让魔戒归你 |
| **精灵**      | **疾行**：每回合可先移动1步，再额外多执行一次传递或抢夺（移动后需同城才有效）。                              |
| **矮人**      | **收买**（抵达城镇5后激活）：每回合都可调换任意两人结算顺序。                                       |
| **霍比特人**    | 理智上限**3点**（别人2点）。开局持戒                                                   |
| **平民**      | 无技能。可能是好人，也可能是坏人。                                                       |
| **萨鲁曼（反）**  | **全局1次**：让指定玩家本回合行动失败。同时拥有表面身份的全部技能。（比如萨鲁曼可以是平民，也可以是霍比特人）               |
| **间谍（反）**   | 拥有表面身份的全部技能。与萨鲁曼互知身份。                                                   |

## 五、人数配置

|    人数     | 配置                |    反方    |
| :-------: | :---------------- | :------: |
|   **5**   | 甘道夫+战士+精灵+矮人+霍比特人 |   1间谍    |
| **6（标准）** | 上述5人+1平民          | 1间谍+1萨鲁曼 |
| **7~10**  | 增加2~3平民           | 增加1~2间谍  |

> 反方**不占额外角色位**，他们是潜伏在这些角色里的叛徒。

## 六、信息规则

**APP/主持人私密告诉你**：你在哪、是否持戒、是否被蛊惑/敲晕、上回合行动结果、毒圈位置。

**你永远不知道**：别人在哪、魔戒在谁手上、别人上回合干了啥（除非你被卷入了）。

**交流**：随便说，随便骗，**别亮屏幕**。

## 七、常见问题

| Q                              | A                                 |
| :----------------------------- | :-------------------------------- |
| 移动失败还能干别的吗？                    | 不能，行动已消耗。                         |
| 被蛊惑后魔戒被抢走，下回合能动吗？              | 能。但理智是0，再拿戒会立刻再次被蛊惑。              |
| 黑门（一个城镇）加理智能超过上限吗：             | 不能                                |
| 萨鲁曼的能力能让白袍行动失败吗？               | 能。这不是收买/蛊惑，白袍不免疫。                 |
| 毒圈和我同回合移动怎么算？                  | 按**回合结束时**你的位置算。成功离开就安全，还在城里就被吞。  |
| 假如我行动失败，我能得到哪些信息？              | UI只会告诉你行动结果（失败与否），但是更具体的原因需要你自己推理 |
| 假如我本回合被敲晕/抢夺/无效，我能知道凶手是谁，在哪里吗？ | 不能得到他目前的位置，需要你推理，但是可以知道他是谁        |
| 被毒圈吞没（死亡）后能知道他是好人坏人吗？          | 玩家死亡后不公布阵营                        |
